# Calculator Mission

Java 사칙연산 계산기 과제입니다.  
기본 사칙연산 계산기에서 시작해, 연산자 enum 분리, 제네릭 기반 숫자 타입 확장, Lambda & Stream 조회 기능, 예외 처리를 단계적으로 적용했습니다.

## 주요 기능

- `+`, `-`, `*`, `/` 사칙연산 수행
- 연산 결과 저장
- 저장된 결과 오름차순 정렬
- 저장된 결과 중 입력값보다 큰 값 조회
- 잘못된 숫자 입력, 잘못된 연산자, 음수 입력, 0 나누기 예외 처리
- `exit` 입력 시 프로그램 종료

## 클래스 구조

### Main.java

사용자 입력과 프로그램 실행 흐름을 담당합니다.

- 숫자 입력
- 연산자 입력
- 계산기 호출
- 결과 출력
- 예외 메시지 출력
- 반복 실행 및 종료 처리

### Calculator.java

초기 버전의 정수형 계산기입니다.

- `int` 타입 기반 사칙연산
- 결과 저장
- 결과 정렬
- 결과 초기화

### ArithmeticCalculator.java

확장된 사칙연산 계산기입니다.

- `N extends Number`를 사용해 숫자 타입을 확장
- 계산 시 `doubleValue()`로 값을 꺼내 `Double` 기준으로 연산
- 결과를 `List<Double>`에 저장
- Stream을 사용해 기준값보다 큰 결과 조회

### OperatorType.java

사칙연산 종류를 enum으로 관리합니다.

- 연산자 기호와 연산 로직을 enum 상수에 연결
- `DoubleBinaryOperator`와 Lambda를 사용해 연산 처리
- 문자 연산자를 enum 타입으로 변환하는 `from()` 메서드 제공

## 적용한 Java 개념

- 클래스와 객체
- 컬렉션 `List`
- 제네릭 `N extends Number`
- enum
- Lambda
- Stream
- 예외 처리
- 메서드 분리
- 결과 저장 및 조회

## 예외 처리 코드

| 코드 | 의미 |
|---|---|
| ERR-1001 | 숫자를 입력해야 하는 위치에 문자를 입력한 경우 |
| ERR-1002 | 지원하지 않는 연산자를 입력한 경우 |
| ERR-1003 | 음수를 입력한 경우 |
| ERR-2001 | 0으로 나누는 등 계산할 수 없는 경우 |
| ERR-1005 | 입력값이 없는 경우 |
| ERR-9001 | 입력 장치가 닫힌 경우 |
